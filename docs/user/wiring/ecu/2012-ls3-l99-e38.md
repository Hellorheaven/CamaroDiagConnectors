# Camaro 2012 V8 LS3/L99 — K20 E38 candidat

**Brochage documentaire uniquement, non qualifié sur banc.** Ne pas appliquer à LSA/E67 ni LFX/E39. Identifier référence GM/HW et vue X1 avant câblage. X1 noir 73 voies, réf faisceau 13716072 selon manuel.
| Connecteur | Broche | Fonction OEM | Circuit |
|---|---:|---|---:|
| X1 | 20 | B+ | 440 |
| X1 | 19 | IGN | 439 |
| X1 | 47 | IGN circuit relais | 5290 |
| X1 | 73 | Masse | 451 |
| X1 | 28 | CAN-H | 2500 |
| X1 | 27 | CAN-L | 2501 |
| X1 | 59 | Commande relais moteur (sortie) | 5991 |
X1-59 n'est pas une entrée alimentation. Le document IO Terminal E38 indique un faisceau minimal J1-19/20, 73, 28/27 ; X1-47 est néanmoins un circuit IGN dans le manuel véhicule. Ne pas improviser sa connexion ; déterminer la séquence nécessaire au mode choisi et la valider. Limites électriques, recovery, accès MCU et écritures physiques à qualifier.
