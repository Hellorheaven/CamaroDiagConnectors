# E39A — fiche de qualification indépendante

**Non qualifié. Aucun raccordement autorisé sur la base de cette fiche.**
L'appellation E39A ne suffit pas à identifier la référence GM, le HW, le véhicule ou le brochage. Ne pas recopier le LFX 2012 ni un pinout E38. Une source générique en ligne attribue +12 V à J1-39/40 (https://ecupinouts.com/en/delco-e39a-gm/), ce qui serait dangereux sur le K20 LFX 2012 où X1-39/40 sont des lignes CAN. Cette source ne sera donc pas utilisée pour établir un faisceau de cette variante.
| Fonction | Broche |
|---|---|
| B+ / IGN / relais | À établir par référence GM/HW |
| Masses | À établir |
| CAN-H / CAN-L | À établir |
| BOOT/BAM/Nexus/JTAG | À établir par MCU et carte |
| EEPROM/NOR | À établir par référence puce |
Tension d'alimentation, limites de courant, séquence, vues de connecteurs, récupération et essais : non établis. Obtenir schéma OEM par VIN, fiche programmateur spécifique et recoupement ; publier une fiche par révision avant qualification. Voir [guide](../README.md).
